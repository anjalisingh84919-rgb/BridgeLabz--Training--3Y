1. Explain the difference between frontend, backend, and full-stack development with
suitable real-world examples.

Frontend Development
Frontend development is the part of a website that users can see and interact with.
It focuses on the design, layout, buttons, images, and menus.
Technologies: HTML, CSS, JavaScript
Example: The Amazon homepage, navigation bar, and product cards.

Backend Development
Backend development is the server-side part of a website. It handles data processing,
authentication, and communication with the database.
Technologies: Node.js, Java, Python, PHP
Example: Checking a user's login credentials and retrieving account information.

Full-Stack Development
A Full-Stack Developer works on both the frontend and backend of a web application.
Example: A developer who designs the login page and also creates the server that verifies the user's login details.
